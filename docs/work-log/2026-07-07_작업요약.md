## 3. 실행한 검증 명령어와 결과

모든 태스크에서 `npm run lint`(`tsc --noEmit`)를 공통 게이트로 사용 — 전부 exit code 0 통과.

주요 실제 검증(전부 통과):
- `decideMessageType`/`generateMessageForCustomer`: 이탈+완주임박 동시 해당 시 완주임박 우선 여부, 재생성 시 최신 상태 재판단 여부를 실 Supabase 데이터로 확인
- 벌크 API: 완주임박+이탈 고객을 한 요청에 섞어 각각 올바른 `message_type`으로 생성되는지 확인, 21건 요청 시 400 거부 확인
- 디자인 토큰: **Task 1에서 타이포 토큰이 `--font-size-*`(잘못된 네임스페이스)로 선언되어 빌드는 성공하지만 유틸리티가 조용히 생성되지 않는 Critical 버그를 리뷰어의 실제 컴파일 테스트로 발견** → `--text-*`로 수정 후 `dist/assets/*.css`에서 `.text-heading-1{font-size:...}` 등 실제 CSS 존재를 그렙으로 재확인
- 각 태스크 완료 후 해당 파일에 금지 색상 클래스(green/red/blue/indigo/기존 amber·brand·stone) 잔존 여부 그렙 확인, 마지막 태스크에서 `App.tsx` 전체 그렙으로 `StampKioskPage`(범위 밖) 외 잔존 없음 확인
- 프로덕션 배포 후 두 차례 모두 `https://rebot-app-owner-dashboard.vercel.app`의 `/api/store`, `/api/dashboard`, `/api/customers`, 신규/구 벌크 라우트 등을 curl로 스모크 확인 — 전부 200(구 라우트는 404 정상)

**미수행**: 브라우저 자동 렌더링 확인 — 샌드박스에 헤드리스 Chromium 의존성 부재로 불가, 코드/그렙/컴파일 결과물 레벨 검증으로 대체(사용자 승인됨). 실제 화면 확인은 사용자가 프로덕션 배포 후 직접 확인 완료.
