## 3. 실행한 검증 명령어와 결과

모든 태스크에서 `npm run lint`(`tsc --noEmit`)를 공통 게이트로 사용 — 전부 exit code 0 통과.

주요 실제 DB/API 검증 (전부 통과):
- `recordManualVisit` 리셋 공식: 일반 케이스(13%10=3) + 정확히 나누어떨어지는 경계값(40%10=0) 둘 다 확인
- `updateCustomerNotes`: 저장/원복/500자 초과 예외 확인
- `getCustomers(..., 'near_completion')`: 90% 진행(포함) vs 30% 진행(제외) 두 케이스로 정확성 확인
- `calcStampCompletionRate`/`calcSecondVisitRate30d`: before/after 델타 방식으로 실제 Supabase 데이터 대비 검증
- 로컬 서버(`npm run start`) + `curl`로 전 API 종단 검증 (`/api/generate-message`, `/api/messages/:id/regenerate`, `/api/visit`, `/api/customers/:id` PATCH, `/api/metrics` 등)
- 프로덕션 배포 후 `https://rebot-app-owner-dashboard.vercel.app/api/store/cafe-rebot`, `/api/metrics/cafe-rebot` 200 확인

**미수행**: 브라우저 육안(Playwright) 검증 — 샌드박스에 헤드리스 Chromium 의존 라이브러리(`libnspr4.so`) 부재로 불가, API/코드 레벨 검증으로 대체 (사용자 승인됨).
